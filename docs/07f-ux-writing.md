# 3.6 — UX Writing TCHATCHA

Toutes les microcopies (français v1 — l'anglais suivra via les tokens i18n).
Ton : chaleureux, direct, simple, positif (voir `07e` §1). Les traductions seront
externalisées dans les fichiers `.arb` (ADR-014).

## Règle de validation UX Writing

- Chaque phrase ≤ 20 mots si possible ; action visible en premier.
- Chaque microcopy est un **token i18n** (`ui.otp.title`, …) — aucune chaîne en dur.
- Les emojis sont réservés aux moments positifs (bienvenue, succès) et aux états vides.
