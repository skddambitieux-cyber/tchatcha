# 3.5 — Identité de marque TCHATCHA

Version : 1.0 (à valider)

---

## 1. Plateforme de marque

### Mission
Mettre en relation les particuliers et les professionnels de proximité, de façon
simple, rapide et fiable — partout en Afrique de l'Ouest.

### Vision
Devenir la **référence de confiance** pour les services de proximité : quand on a
besoin de quelqu'un de sérieux, on pense à TCHATCHA.

### Valeurs
| Valeur | Traduction produit |
|---|---|
| **Confiance** | Badge vérifié, Trust Score, avis authentiques, litiges arbitrés |
| **Proximité** | Des pros près de chez vous, dans votre langue, votre monnaie |
| **Rapidité** | Trouver en 3 gestes, réponse des pros en minutes |
| **Qualité** | Vérification, avis multi-critères, engagement de prestation |
| **Inclusion** | Sans smartphone puissant ni gros forfait : apps légères, SMS, espaces |
| **Fierté locale** | Pensé et construit pour le Bénin, l'Afrique de l'Ouest |

### Promesse
> **« Le bon professionnel, près de chez vous, en toute confiance. »**

### Personnalité
Chaleureuse, énergique, fiable, moderne. Une marque qui a le sourire et les
deux pieds dans le réel : le chantier, la boutique, le service à domicile.

### Ton
Chaleureux et direct. Simple. Positif. Jamais condescendant. On tutoie l'utilisateur
(cas du Bénin et de l'Afrique de l'Ouest), on parle concret, on évite le jargon
administratif.

### Voix
- Courtes phrases. Verbes d'action.
- Français simple, traduisible (anglais + langues locales) sans perte de sens.
- On ne menace pas : on accompagne. (« Votre code n'est plus valide » plutôt que « Code invalide ».)
- On célèbre les victoires : « Devis reçu ! », « Prestation confirmée 🎉 » (emoji sobre, dans le ton).

### Slogan (propositions à valider)
1. **« Le bon pro, près de chez vous. »** (recommandé — court, géo, promesse)
2. « Trouvez. Comparez. Confiez. » (process)
3. « La confiance commence à proximité. » (émotionnel)
4. « TCHATCHA — Le service, en confiance. » (marque)

## 2. Nom & origine

**TCHATCHA** : nom court, sonore, mémorisable, facile à prononcer dans toutes les
langues de la région. Évoque la **recherche / la quête du bon service** (à valider
et enrichir avec un locuteur local : la marque peut l'assumer comme un mot inventé
et chaleureux, "le bruit de l'action, de la vie qui bouge").

- Utilisable comme verbe : « Tchatcha un plombier. » → forte mémorisation.
- Adaptable : TCHATCHA Pro, TCHATCHA Livreur, TCHATCHA Admin, TCHATCHA Business.

## 3. Logo

### Direction créative (à dessiner ensuite)
- **Mot-symbole** : une marque distinctive = deux éléments en un :
  - une **punaise de localisation** dont la tête devient une **étincelle/check** (= trouver + confiance) ;
  - ou un **nœud/nounou** (nœud du cordon) stylisé = le lien entre client et pro.
- Typographie : géométrique et ronde (famille Outfit Bold), le mot **TCHATCHA** en capitales.
- Couleurs : vert TCHATCHA + orange Soleil (voir tokens), fond blanc.
- Le logo doit rester lisible à 24 px (favicon) et en monochrome (gravure, watermark).

### Déclinaisons
| Élément | Usage |
|---|---|
| Logo principal | Splash, accueil, site |
| Logo secondaire (symbole seul) | App icon, favicon, notifications |
| App icon | Fond vert, symbole blanc, coins arrondis 20 % |
| Favicons | 16/32/48 px + apple-touch-icon + manifest web |
| Variante monochrome | Documents, tampons, watermark |
| Variante sombre | Sur fonds verts foncés |

## 4. Palette de marque (résumé — détails dans `07d-design-tokens.md`)

| Rôle | Couleur | Hex |
|---|---|---|
| Vert TCHATCHA (primaire) | Confiance, action | `#1B7A4D` |
| Vert foncé (pressé) | Interaction primaire | `#14633E` |
| Orange Soleil (secondaire) | Énergie, CTA secondaires, promotions | `#FF8A3D` |
| Jaune (accent) | Prix, badges, offres | `#F2A93B` |
| Encre (neutre foncé) | Textes | `#1A1D1F` |
| Fond clair | Surfaces | `#F7F8FA` / blanc |

Justification : le **vert** = confiance, croissance, identité ouest-africaine ;
l'**orange** = chaleur, énergie, hospitalité. Couple complémentaire, distinctif sur
les stores, accessible (contrastes AA).

## 5. Charte graphique

| Règle | Valeur |
|---|---|
| Formes | Coins arrondis généreux (radius 16/24), pas de formes agressives |
| Illustrations | Personnages chaleureux (style plat, teintes chaudes), scènes locales (chantier, boutique, livraison, famille) — à créer |
| Photographie | Vrais métiers de la région, lumière naturelle, sourires ; jamais de clichés génériques étrangers |
| Motion | Éléments rapides mais doux (150–400 ms) ; la réussite se célèbre (check animé) |
| Iconographie | Lignes épaisses (2 px), coins arrondis, style cohérent (Material Symbols ou Lucide) |
| Sons (app) | Optionnels, discrets, jamais agressifs (paiement réussi = son bref et chaleureux) |

## 6. Le badge « Professionnel vérifié TCHATCHA »

Objectif stratégique : **la confiance comme avantage concurrentiel**.

| Élément | Spécification |
|---|---|
| Visuel | Bouclier vert TCHATCHA + check blanc, ou rond vert avec check |
| Libellé | « Vérifié TCHATCHA » (court) / « Professionnel vérifié TCHATCHA » (long) |
| Emplacement | Résultats de recherche, fiche pro (en-tête), cartes de chat, avis du pro |
| Conditions | Accorde uniquement après validation humaine du dossier (CIN + selfie + documents) |
| Promesse associée | Fiabilité · Rapidité · Qualité · Sécurité (l'utilisateur doit y penser automatiquement) |
| Accompagnement | Trust Score visible à côté (note + missions + taux de réponse) |

Règle produit : un pro vérifié ne peut **jamais** perdre son badge sans décision
tracée (audit) — le badge est un actif de confiance.
